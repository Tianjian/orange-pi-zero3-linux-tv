# 10 · H618 内核构建验证报告

> 本报告记录 **2026-11-02 在本机实际交叉编译** Orange Pi Zero 3（H618）官方 6.1 内核的全过程与产物证据。
> 结论：**编译链、配置、设备树、模块 ABI 全部通过机器验证**；启动与驱动 probe 必须在真板复测（本机无板）。
>
> 方案见 [docs/09_H618内核适配与编译方案.md](09_H618内核适配与编译方案.md)；
> 机制见 [docs/07](07_orangepi-build内核机制与配置分析.md)；主线/社区见 [docs/08](08_社区与主线调研.md)。

## 4. 未验证 / 必须在真板复测

| # | 项目 | 原因 | 上板方法 |
|---|---|---|---|
| H1 | U-Boot 加载 Image/DTB、内核启动 | 无板 | 串口看 U-Boot `load`/`booti`，确认 `6.1.31-sun50iw9` |
| H2 | rootfs 挂载、systemd 启动 | 无板 | 用官方镜像替换内核；或 `bindeb-pkg` 后 `dpkg -i` |
| H3 | eMMC/SDIO WiFi 枚举 | 无板 | `dmesg \\| grep mmc1`、`lsmod \\| grep -E "uwe5622\\|sprdwl"` |
| H4 | 以太网 RGMII 实际吞吐 | 无板 | `iperf3` 双向；确认 PHY 1Gbps 协商 |
| H5 | HDMI/DE 输出 | 无板 | 接显示器，`modetest`/`dmesg` |
| H6 | 音频 codec 播放 | 无板 | 13pin 扩展板 + `aplay`/`speaker-test` |
| H7 | IR 接收 | 无板 | 13pin 扩展板 + `evtest` |
| H8 | VPU 硬解（cedrus） | 无板 + 需用户态 | `v4l2-ctl --list-devices`、ffmpeg v4l2-request |
| H9 | GPU（panfrost） | 无板 | 需先打开 `gpu` overlay；`dmesg \\| grep panfrost` |
| H10 | 温度/降频/长时间稳定 | 无板 | 满载 1h + `thermal_zone*` |
| H11 | 5.4 分支构建 | 未克隆 5.4 源码 | `./scripts/build_kernel.sh --branch 5.4`（会拉 ~2GB） |

> 结论：**“编译成功”只证明工具链/配置/DTS/ABI 正确，不证明驱动能 probe**。
> 上板验收见 `docs/00` F 节与 `docs/05`。

## 6. 已知限制

1. **没有真板**：所有 L4 启动/外设项未验证；本机只检测到 CH340（`/dev/ttyUSB0`）但无对端。
2. **只构建了 6.1**：5.4 分支未克隆源码，只做了 .config 符号级对照（`docs/07` §6）。
3. **主线片段只在厂商树上验证**：主线 6.18/7.0 的实际符号/依赖需在对应源码树再跑一次 `merge_config`。
4. **未做 deb 打包**：本方案输出 Image/dtb/modules；要出 `linux-image-*.deb` 用 `make bindeb-pkg` 或走 orangepi-build。
5. **模块签名**：`MODULE_SIG_ALL=y` 会为模块生成签名；自编模块无签名仍可加载（未开 `FORCE`），量产需统一策略。
6. **构建可重复性**：版本串含主机名与编译时间，非 bit-for-bit 可重复；如需可复现构建，应固定 `KBUILD_BUILD_TIMESTAMP`/`KBUILD_BUILD_USER`。

## 7. 与官方 SDK 的差异

| 项 | 本验证 | orangepi-build |
|---|---|---|
| 内核源码 | `orange-pi-6.1-sun50iw9@7114452` | 同一分支（运行时拉取） |
| 配置 | 官方 `.config` + `olddefconfig` | 同 |
| 工具链 | 11.2（固定） | `find_toolchain` 按 `>8.0` 可能选 9.2（见 docs/07 §2） |
| 镜像类型 | `Image` | `Image`（arm64.conf） |
| 并行/缓存 | `-j nproc`，无 ccache | `-j CPUS*1.5`，默认 ccache |
| 打包 | 无（可选 bindeb-pkg） | bindeb-pkg + deb |
| 耗时 | 24m41s（8 核） | 取决于 ccache/机器，通常更久（含 deb/rootfs） |
